نصب و راه‌اندازی سرور بیگ‌بلوباتن

راهنمای گام‌به‌گام برای ساختن کلاس آنلاین خودتان؛ از سرور خام تا اتاقی که معلم‌ها و دانش‌آموزان در آن وارد می‌شوند.

۱پیش‌نیازها و آماده‌سازی سرور




Ubuntu 22.04نسخه تازه و تمیز


4 CPU · 16 GBهسته و رم؛ ۵۰ گیگ فضای خالی


80 · 443 · 16384–32768پورت‌های TCP و UDP (بازه آخر UDP)




با SSH وارد سرور شوید و دستورات را به ترتیب اجرا کنید.




به‌روزرسانی لیست پکیج‌ها
آخرین نسخه نرم‌افزارها را از مخزن اوبونتو می‌گیرد.
sudo apt update


ارتقاء همه پکیج‌ها
گزینه -y یعنی همه سوال‌ها را بله بگو.
sudo apt upgrade -y


پاک‌سازی فایل‌های اضافی
پکیج‌های غیرضروری حذف می‌شوند تا فضا آزاد شود.
sudo apt autoremove -y


غیرفعال کردن موقت فایروال
برای نصب بدون مشکل، فایروال را موقتاً خاموش می‌کنیم.
sudo ufw disable









۲تنظیم دامنه (DNS)


یک دامنه یا ساب‌دامنه مثل bbb.danyar.ir را به آی‌پی عمومی سرور اشاره دهید. بدون این کار، مراحل بعدی (به‌خصوص SSL) خطا می‌دهند.












ورود به پنل مدیریت دامنه
به بخش مدیریت DNS دامنه‌تان بروید.


ساخت رکورد A
یک رکورد از نوع A بسازید و مقدار آن را برابر آی‌پی سرور بگذارید.










افزودن دامنه به Cloudflare
در dash.cloudflare.com وارد شوید، Add a domain را بزنید و دامنه اصلی (مثلاً danyar.ir) را وارد کنید. پلن Free کافی است.


تغییر Nameserver
Cloudflare دو نیم‌سرور به شما می‌دهد. در پنل ثبت دامنه، نیم‌سرورهای قبلی را با این دو جایگزین کنید و منتظر بمانید تا وضعیت دامنه Active شود (چند دقیقه تا چند ساعت).


ساخت رکورد A
از منوی DNS ← Records روی Add record بزنید و این مقادیر را وارد کنید:


فیلدمقدار


TypeA


Namebbb


IPv4 addressIP of your server


Proxy statusDNS only (ابر خاکستری)


TTLAuto




مهم: پروکسی را خاموش (ابر خاکستری) نگه دارید. بیگ‌بلوباتن صدا و تصویر را روی پورت‌های UDP می‌فرستد و Cloudflare این ترافیک را از مسیر پروکسی عبور نمی‌دهد؛ با ابر نارنجی، کلاس بالا می‌آید ولی صدا و تصویر کار نمی‌کند. صدور SSL هم باید مستقیم روی سرور انجام شود.


بررسی: بعد از چند دقیقه با این دستور مطمئن شوید دامنه به آی‌پی سرور اشاره می‌کند:

ping bbb.danyar.ir









۳نصب بیگ‌بلوباتن با اسکریپت


حدود ۳۰ دقیقه طول می‌کشد. دامنه و ایمیل را با مقادیر خودتان عوض کنید.


wget -qO- https://raw.githubusercontent.com/bigbluebutton/bbb-install/v3.0.x-release/bbb-install.sh | sudo bash -s -- -w -v jammy-300 -s bbb.danyar.ir -e admin@danyar.ir -w -g


    

  • wget -qO- دانلود فایل از اینترنت؛ -q بی‌صدا و -O- خروجی مستقیم
    • 

  • bbb-install.sh آدرس اسکریپت نصب خودکار از سایت رسمی
    • 

  • | sudo bash -s -- محتوای دانلودشده را اجرا می‌کند
    • 

  • -w فایروال UFW را نصب و پورت‌های لازم را باز می‌کند
    • 

  • -v jammy-300 نسخه ۳.۰ را روی اوبونتو ۲۲.۰۴ نصب می‌کند
    • 

  • -s bbb.danyar.ir دامنه‌ای که برای سرور انتخاب کرده‌اید
    • 

  • -e admin@danyar.ir ایمیل برای گواهینامه SSL از Let's Encrypt
    • 








۴بررسی نصب و گرفتن Secret




بررسی سلامت نصب
اگر همه‌چیز سبز بود، نصب درست انجام شده است.
sudo bbb-conf --check


گرفتن رمز Secret
این رمز برای اتصال نرم‌افزارهای دیگر به بیگ‌بلوباتن لازم است. حتماً یادداشتش کنید.
sudo bbb-conf --secret









۵فارسی‌سازی کامل




ویرایش فایل تنظیمات زبان
خط overrideLocale: null را پیدا کنید و به overrideLocale: fa_IR تغییر دهید. ذخیره: Ctrl+X ، Y ، Enter
sudo nano /usr/share/meteor/bundle/programs/server/assets/app/config/settings.yml


ویرایش فایل ظاهر کلاس
این خطوط را به انتهای فایل اضافه کنید و ذخیره کنید.
sudo nano /etc/bigbluebutton/bbb-html5.yml


public:
  app:
    defaultSettings:
      application:
        locale: fa_IR


ری‌استارت بیگ‌بلوباتن
بعد از هر تغییر لازم است؛ حدود ۲ دقیقه طول می‌کشد.
sudo bbb-conf --restart









۶نصب و فارسی‌سازی گرین‌لایت


گرین‌لایت همان وب‌سایتی است که کاربران با آن ثبت‌نام می‌کنند، اتاق می‌سازند و جلسات را می‌بینند.


wget -qO- https://raw.githubusercontent.com/bigbluebutton/bbb-install/v3.0.x-release/bbb-install.sh | sudo bash -s -- -g


بعد از نصب، وارد سایت شوید (مثل bbb.danyar.ir)، روی آواتار بالا سمت راست کلیک کنید، Settings را باز کنید و زبان را روی فارسی بگذارید.







۷ساختن ادمین اصلی


docker exec -it greenlight-v3 bundle exec rake admin:create['مدیرکل','admin@danyar.ir','MyStrongPass123!']


    

  • docker exec به درون یک کانتینر (محیط مجازی کوچک) برو
    • 

  • -it greenlight-v3 مشخص می‌کند به کانتینر گرین‌لایت بروی
    • 

  • rake admin:create اسکریپت داخلی ساخت ادمین
    • 

  • ['نام','ایمیل','رمز'] مشخصات ادمین
    • 



توجه: رمز نمونه را حتماً با رمز قوی و مخصوص خودتان عوض کنید.


اگر دستور بالا خطا داد، این را اجرا کنید:


docker exec -it greenlight-v3 bundle exec rake admin:create


حالا با همان ایمیل و رمز وارد سایت شوید. در منوی بالا گزینه Organization را می‌بینید که مخصوص ادمین است.







۸تنظیم ثبت‌نام معلم‌ها


وارد Organization شوید و به Site Settings بروید.




ثبت‌نام عمومیگزینه «Allow anyone to sign up» را فعال کنید تا هر معلم خودش ثبت‌نام کند.


ثبت‌نام با دعوت‌نامهگزینه بالا را غیرفعال کنید، از بخش Users روی «Invite User» بزنید و ایمیل معلم را وارد کنید.









۹ساخت اتاق شخصی توسط معلم




شروع ساخت اتاق
بعد از ورود به سایت، روی «+ شروع اتاق جدید» (Create Room) کلیک کنید.


نام کلاس
در کادر Room Name نام کلاس را بنویسید، مثلاً «کلاس ریاضی دهم».


تنظیمات پیشرفته (اختیاری)
در Advanced Settings می‌توانید مثلاً اجازه ورود قبل از مدرس را فعال کنید.


ساخت اتاق
روی Create کلیک کنید.


شروع کلاس
روی «ورود به اتاق» (Join Room) بزنید. بیگ‌بلوباتن باز می‌شود و معلم به عنوان مدرس (Moderator) وارد می‌شود.


دعوت دانش‌آموزان
از منوی بالا گزینه Invite را انتخاب و لینک را کپی کنید.


ارسال لینک
لینک را از طریق واتساپ، تلگرام یا ایمیل برای دانش‌آموزان بفرستید.









۱۰نحوه ورود دانش‌آموز به کلاس




کلیک روی لینک
دانش‌آموز روی لینکی که معلم فرستاده کلیک می‌کند.


وارد کردن نام
فقط نامش پرسیده می‌شود، مثلاً «علی رضایی».


ورود به کلاس
به عنوان شنونده (Viewer) وارد می‌شود. حساب کاربری و ثبت‌نام لازم نیست.









۱۱برندسازی (لوگو و اسم سایت)




تغییر لوگو از پنل مدیریت (راحت‌ترین روش)
Organization ← Site Settings ← بخش Branding Image، آدرس اینترنتی لوگوی جدید را وارد کنید (لوگو باید روی یک هاست عمومی آپلود شده باشد) و روی «Change Image» بزنید.


تغییر نام سایت
در همان صفحه، گزینه Application Name یا Site Title را پیدا کنید، «BigBlueButton» را با «مدرسه مجازی دانیار» عوض و ذخیره کنید.


تغییر لوگو از خط فرمان (اگر روش قبل جواب نداد)
لوگو را با نام logo.png در پوشه زیر بگذارید و لینک را بسازید:


sudo mkdir -p /var/bigbluebutton/customLogo/


sudo ln -sf /var/bigbluebutton/customLogo/logo.png /var/www/bigbluebutton-default/assets/images/logo.png
